Repositório de estudos com aulas, exercícios e exemplos práticos de HTML e CSS. O objetivo é acompanhar a evolução nos fundamentos de desenvolvimento web e manter um histórico organizado dos arquivos criados em aula.

## Conteúdo

- Páginas HTML numeradas por aula.
- Arquivos CSS separados para praticar estilização.
- Imagens usadas nos exercícios.
- Exemplos introdutórios de estrutura, semântica e layout.

## Tecnologias

- HTML5
- CSS3
- Git e GitHub
